# Pol Desaf-IA — Curso de Agentes de IA con Claude

> Aprende a construir Agentes de IA desde cero, en español, sin necesidad de experiencia previa en programación.

Creado por **Pablo David Moya** para la comunidad de IA en Latinoamérica y España.

---

## ¿Qué vas a aprender?

En este curso vas a pasar de no saber nada sobre agentes de IA a construir sistemas capaces de tomar decisiones, usar herramientas y resolver tareas complejas — todo usando **Claude**, el modelo de IA de Anthropic.

No necesitás saber programar de antemano. Cada lección está diseñada para que cualquier persona pueda seguirla.

## Requisitos

- Python 3.10 o superior
- Una cuenta en [Anthropic Console](https://console.anthropic.com/) para obtener tu API key
- Ganas de aprender

## Configuración inicial

```bash
pip install anthropic python-dotenv
```

Creá un archivo `.env` en la carpeta raíz con tu API key:

```
ANTHROPIC_API_KEY=tu_api_key_aqui
```
